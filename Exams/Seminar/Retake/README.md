# Поправителен изпит - Структури от Данни и Алгоритми

> **Забележка:** Всяка задача може да бъде решена по повече от един начин - с различни структури от данни и алгоритми. Приема се всяко коректно решение, което спазва ограниченията в условието.

## Задача 1

- Аналогична задача: [**Sort Array by Increasing Frequency**](https://leetcode.com/problems/sort-array-by-increasing-frequency/) - Лесна

### Условие

От стандартния вход се прочита число **N** – броят елементи в масива, а на следващия ред – **N** цели числа.
Да се сортира масивът във възходящ ред спрямо честотата (броя срещания) на стойностите и да се принтира в конзолата. Ако няколко различни стойности имат еднаква честота, те се подреждат в низходящ ред спрямо самата стойност.
Числата са в диапазона `INT_MIN` до `INT_MAX`.

### Пример

**Вход:**

```
9
-1 1 -6 4 5 -6 1 4 1
```

**Изход:**

```
5 -1 4 4 -6 -6 1 1 1
```

## Задача 2

- Аналогична задача: Няма. Лесна

### Условие

Дадена е структурата:

```cpp
struct Node {
    int data;
    Node* next;

    Node(int value) {
        data = value;
        next = nullptr;
    }
};
```

Да се имплементира функция със следната дефиниция:

```cpp
Node* processList(Node* head);
```

която:

- приема указател към главата на едносвързан списък от цели числа;
- премахва всеки възел, чиято стойност е точно с 1 по-голяма от стойността на предходния възел в първоначалната последователност;
- преброява всички премахнати възли;
- след обработката добавя в края нов възел, чиято стойност е броят на премахнатите възли;
- връща указател към главата на получения списък.

**Важно:** Сравнението се прави спрямо съседните стойности в първоначалния списък. Ако например имаме `7 → 8 → 9`, и 8, и 9 отговарят на условието за премахване.

**Граничен случай:** при празен входен списък няма премахнати възли, затова функцията трябва да създаде и върне списък с един възел със стойност 0.

## Задача 3

- Аналогична задача: [**Number of Operations to Make Network Connected**](https://leetcode.com/problems/number-of-operations-to-make-network-connected/) - Лесна

### Условие

Дадени са **N** компютъра, номерирани от 0 до N-1, свързани с **M** мрежови кабела.
Всеки кабел свързва директно два различни компютъра. Кабелът се описва с двойка числа `[a,b]`, което означава, че компютрите `a` и `b` са директно свързани.
Два компютъра могат да си комуникират, ако между тях има път от кабели (директно или през други компютри).

Позволена ви е следната операция: избирате произволен кабел, който в момента свързва два директно свързани компютъра, изключвате го и го включвате между произволни други два компютъра, които в момента не са директно свързани. Нови кабели не могат да се купуват.

Да се имплементира функция със следната дефиниция:

```cpp
int makeConnected(int n, vector<vector<int>>& connections);
```

която намира минималния брой операции, необходими всеки компютър да може да комуникира с всеки друг.
Ако това е невъзможно, функцията връща -1.

- `n` - броят компютри
- `connections` - масив от ребра от вида `[a,b]`

### Примери

**Вход:**

```
n = 6, connections = [[0,1],[0,2],[0,3],[1,2],[1,3]]
```

**Изход:**

```
2
```

**Вход:**

```
n = 6, connections = [[0,1],[0,2],[0,3],[1,2]]
```

**Изход:**

```
-1
```

## Задача 4

- Аналогична задача: [**Split a Circular Linked List**](https://leetcode.com/problems/split-a-circular-linked-list/) - Средна

### Условие

Даден е цикличен едносвързан списък с поне два възела. Цикличен свързан списък е списък, в който `next` указателят на последния възел сочи към първия възел.

Да се имплементира функция със следната дефиниция:

```cpp
vector<ListNode*> splitCircularLinkedList(ListNode* list);
```

която разделя списъка на два циклични свързани списъка така, че:

- първият да съдържа първата половина от възлите – точно `ceil(n/2)` на брой, в реда, в който се срещат в оригиналния списък;
- вторият да съдържа останалите възли, отново в оригиналния им ред.

Функцията трябва да върне масив с указатели към главите на двата новополучени списъка.

### Ограничения

- Функцията **НЕ ТРЯБВА** да създава нови възли – разделянето да се извърши само чрез пренасочване на указатели!

### Пример

**Вход:**

```
[1,5,6,4,7]
```

**Изход:**

```
[[1,5,6],[4,7]]
```

## Задача 5

- Аналогична задача: [**Lowest Common Ancestor of a Binary Tree**](https://leetcode.com/problems/lowest-common-ancestor-of-a-binary-tree/) - Трудна

### Условие

Дадена е структурата:

```cpp
struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
};
```

Да се намери най-близкият общ предшественик на два възела в двоично дърво.
Най-близкият общ предшественик на два възела `p` и `q` е най-ниско разположения възел, който има `p` и `q` за свои наследници, като считаме, че всеки възел е предшественик самия себе си.

Да се имплементира функция със следната дефиниция:

```cpp
TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q);
```

където `root` е коренът на дървото, а `p` и `q` са двата възела, чиито най-близък общ предшественик трябва да бъде върнат от функцията.
Дървото винаги ще има поне един възел и `p` и `q` ще бъдат възли в него.
